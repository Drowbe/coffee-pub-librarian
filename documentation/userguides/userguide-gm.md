# Running a Session

**Audience:** A GM using Librarian at the table.

The GM's workflow in the order a session actually runs, and which guide covers each piece in
detail.

## Before the session

**Get the material in.** If you have written anything since last time, import it rather than
retyping it -- see [Importing and exporting](userguide-importing.md). Re-importing updates
what already exists instead of duplicating it, so a corrected file is safe to run again.

**Place pins for where you expect the party to go.** Pinning a location entry and the
objectives that happen there means you are not hunting for them mid-scene. See
[Canvas pins](userguide-canvas-pins.md).

**Check what the party can already see.** The entry count at the bottom of the codex is
yours, not theirs. If you want to know what a player sees, ask one, or check individual
entries' eye controls.

## During the session

**Reveal as they earn it.** The eye control on a codex entry row is the whole mechanism:
**Show to Players** the moment the party learns something. Tell them you have done it -- a
player with the codex already open will not see the new entry until they reopen the window.

**Tick objectives off as they happen.** Left-click completes, right-click fails,
middle-click hides. Quest progress follows automatically from how many objectives are
complete. See [Quests and objectives](userguide-quests.md).

**Look things up without leaving the canvas.** The codex is a lookaside -- it sits beside
the map rather than filling the screen. Search by name, or filter by tag when you remember
what something *was* rather than what it was called.

**Double-click a pin** to jump to whatever it stands for.

## After the session

**Set quest statuses.** **Set Status** on a quest's options menu: Complete, Incomplete,
Failed, or Hidden.

**Reveal anything you meant to and did not.** This is the most commonly forgotten step, and
it is invisible -- nobody complains about an entry they do not know exists.

**Export if you want a backup.** See [Importing and exporting](userguide-importing.md), and
note the rule there about never exporting with Librarian disabled.

## Things worth knowing once

**Everything starts hidden.** New codex entries are created invisible to players, whether
you make them by hand or by import. This is deliberate -- an entry revealed by accident
cannot be un-revealed from anyone's memory.

**The plot hook is always yours.** It never renders for a player, on the card or on the
page, so it is the safe place for what the party has not worked out yet.

**GM hints live inside objectives.** Text between double pipes -- `||like this||` -- is
invisible to players, so a hint can sit in the objective it belongs to rather than in a
separate note.

**Names link themselves later.** Referencing an entry you have not written yet is fine and
intended; it becomes a link when the entry exists. You do not have to create things in
order.

**Auto-Discover** reveals codex entries matching items the party is carrying, which is a
quick way to catch up after a session where they collected a lot.
